# Codex monitor tools

## Register
Product — an operator tool for inspecting and testing tweet monitoring.

## Platform
Web, local desktop browser with responsive layouts.

## Users and purpose
The developer needs to add controlled tweets, adjust the polling interval,
inspect real monitor decisions, and compare offline heuristics with OpenRouter.

## Design principles
- Make local data, simulation mode, and actual model calls explicit.
- Keep the tweet composer, timer, and outcomes visible together.
- Show initial seeding and historical suppression as understandable outcomes.
- Use the existing dashboard's restrained blue, neutral surfaces, and system typography.
- Preserve form drafts while results refresh; support keyboard navigation.
